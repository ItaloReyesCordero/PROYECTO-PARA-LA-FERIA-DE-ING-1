# Desglosa

**Mapas, diagramas de flujo y de secuencia interactivos a partir de tu código, sin IA.**

> En construcción. La especificación completa está en [`SPEC.md`](SPEC.md).

## Instalación (Windows, con uv)

```powershell
uv sync
uv run desglosa setup     # descarga las gramáticas una sola vez (necesita internet)
uv run desglosa doctor    # verifica que todo esté listo
```
